# **App Name**: Anexas

## Core Features:

- Service Catalog: Showcase the digital agency's service offerings (eCommerce, Content Writing, Digital Products, etc.).
- Project Statistics: Display key statistics such as projects completed, happy clients, years of experience, and 24/7 support availability.
- Contact Form: A contact form for potential clients to reach out and inquire about services.
- Case Study Showcase: Showcase the work you've done using generative AI powered search capabilities that suggest previously done work that would match the current search query as a tool to guide the potential client towards similar cases.

## Style Guidelines:

- Primary color: Electric blue (#FFFFFF) for a modern, digital feel.
- Background color: Dark slate blue (#243647) for a sophisticated and clean aesthetic.
- Accent color: Cyan (#00FFFF) for highlighting interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif, with a modern and neutral feel.
- Simple, line-based icons for services and key features.
- Clean and modern layout with a focus on visual hierarchy.
- Subtle transitions and hover effects for a polished user experience.
